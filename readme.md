# Sample Data for Topic Modeling

The data in this folder is configured for experimenting with [jsLDA](https://mimno.infosci.cornell.edu/jsLDA/), an in-browser topic modeling tool developed by David Mimno's research group at Cornell that allows you to perform topic modeling without having to download any software or learn any programming. jsLDA allows users to upload both their own corpus as well as a list of stop words that they want to exclude from the data, and it also allows you to download the results of the analysis for further investigation. According to the tool's documentation, "jsLDA works in Chrome, Safari, and Firefox," so if you typically use a different browser from these, you might have to switch.

In the `stop-words` folder are various lists of stop words, which we will discuss together. 

## Datasets

+ `frankenstein.txt` includes the full text of Mary Shelley's novel Frankenstein, divided by paragraph and chapter. This is a useful dataset for learning the basics of how topic modeling and the jsLDA tool work, but a single novel is likely too small a dataset for effective topic modeling, which is a method designed for text analysis at scale.
+ The folder `lyrics-by-genre` includes separate files for the genres represented in Prof. Underwood's larger `lyricsformimno.csv` set described below. I divided this data because using the full set tends to produce topics that largely reflect individual genres rather than topics across genres.
+ In the `Underwood` folder are a few datasets compiled by Prof. Ted Underwood. From the included readme.md, these include:
    +   `poeficformimno.tsv` "has about 1000 page-length texts drawn from public-domain poetry and fiction from around 1800 to 1921." These documents are about a page of text apiece.
    +   `lyricsformimno.csv` "has about 26000 songs from the early 20th century to 2021, drawn ultimately from Genius, and more prixomately from Bruno Kreiner's dataset on HuggingFace." Please note that these lyrics are uncensored, and may include language some might find offensive.
+ The `robbins-eagle`folder includes the full digitized text, in a few forms listed below, from the [the Robbins Eagle](https://www.loc.gov/item/sn2008060212/)—an African-American newspaper in Robbins, Illinois—between 1951-1963. There is a custom stop words file, `robbins-stoplist.txt`, that I would recommend using for these datasets. These are larger datasets and you should anticipate them taking awhile to iterate in the jsLDA tool. Here are the files in that folder:
    + For `robbins-eagle-pages.tsv`, each document is an individual pages of a newspaper issue. This is how the data are downloaded from the Library of Congress' Chronicling America collection, but pages are not necessarily the best unit of analysis for a topic model.
    + `robbins-eagle-articles.tsv` and `robbins-eagle-ads.tsv` result from a machine learning pipeline that sought to divide the data by article. Given the complexities of historical newspaper pages and OCR, the results are not perfect—some ads likely bleed into the articles data, and some articles likely concatenate or are split incorrectly. But overall, this separates articles into documents, which should result in more coherent topics, and ads are included as a separate file, as they operate quite differently from articles. The articles dataset includes 6,176 documents and 873k words, while the ads data includes 2,907 documents and 182k words.
+ In the VRT folder are files prepared by Avery Blankenship (Assistant Professor, Texas A&M English) and Jess Frye (PhD student, UIUC iSchool) for their work with the [Virality of Racial Terror Project](https://www.vrt.viraltexts.org/). The documents here are extracted articles from newspapers. Please note: this data is drawn from historical newspapers describing violent and often racist events, and include offensive language. These data include:
    +   `klan-data.tsv`, a set of articles describing domestic terrorism by the Klu Klux Klan during the late 19th and early 20th centuries.
    + `riot-data.tsv`, a set of articles describing racialized mob violence during the late 19th and early 20th centuries.
+ `scifi-chunks.tsv` includes the full text of the most popular 70(ish) science fiction novels from Project Gutenberg. As [the Data-sitters Club notes in their topic model tutorial](https://datasittersclub.github.io/site/dsc20/), full novels are rarely a good document size for topic modeling, so these have been chunked into 500-word sequences. I strongly recommend using the `scifi-stoplist.txt` as your stop words list for this data, as it removes many of the character names that can skew results with this dataset. Even so, this dataset remains a little wonky—the wide temporal spread, for instance, can distort the topics—and one I hope to refine for future years.
